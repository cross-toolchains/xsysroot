# xsysroot

**Unified cross-platform sysroot manager.**

Coordinates minimal target sysroots across Windows (`xwin`), macOS (`xmac`), iOS (`xios`), Android (`xdroid`), Linux (`xlinux`), and OpenHarmony (`xohos`).
